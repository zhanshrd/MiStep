# Mi Step 1.0.1

本次更新汇总自 1.0.0 正式版以来的新增功能与修复。

## 新增功能

- 新增顶部横屏窗口，可在一个主区域和三个副任务之外，再保留一个可直接操作的应用。点击空位「＋」收纳当前主屏应用，支持应用内点击、换页和返回。
- 新增顶部双指翻面手势，上下滑动可切换控制中心与横屏窗口，也可从控制区第三页进入。主屏与顶部任务切换采用真实应用画面的中心收展动画；返回控制中心时，已有主屏应用保持原样，顶部任务继续保留。
- 新增快捷应用自定义：长按应用栏打开毛玻璃选择框，支持搜索、多选和按选择顺序固定，常用应用放在最前，配置退出或重启后保留。
- 新增应用分身支持，本体和分身可同时收纳、分别切换，从桌面打开时也会对应各自的任务。
- 新增全屏防误触入口规则：全屏应用内先拉出状态栏，保持通知和快捷面板未展开，再从上角横滑进入一步。

## 修复与优化

- 修复部分带译文歌词的显示与高亮错行，原文和译文按对应歌词一起排列。
- 修复清空剪贴板历史后，原有内容再次出现的问题。
- 修复部分主题下控制中心图标缺失、显示异常或重叠的问题，系统开关使用原生图案，付款码和乘车码保留原有图标。
- 优化剪贴板列表和操作按钮样式，统一清空、删除与关闭图标。
- 精简模块推荐作用域，普通使用只需系统框架和系统界面；小米输入法的横屏悬浮兼容按需开启，普通应用无需勾选。

## 升级说明

已安装同包名、同签名的 1.0.0 或 1.0.1 测试版，可直接覆盖安装。升级前先退出一步，安装后正常重启手机。

在 LSPosed 中保留系统框架 `android` 和系统界面 `com.android.systemui`。如需阻止小米输入法在横屏时自动切成悬浮键盘，可另外勾选 `com.xiaomi.type`。升级不会自动清除已有的多余作用域，可自行取消；无需勾选设置、抖音或音乐播放器。

当前适配目标为 Android 17 / 澎湃 OS 4，需 Root 和 LSPosed。部分机型主区域不缩放、部分图文打开评论时图片错位，以及与其他手势模块的兼容问题仍在跟进，本版不将这些问题列为已修复。
