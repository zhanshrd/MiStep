# 1.0.1 发布检查

正式版本 `1.0.1 / 1000034` 从全新隔离目录完整编译 144 份 Java 源码和原生 C++ 输入库，项目全套离线测试通过。签名身份与最终测试候选及既有正式版一致，APK 的签名、16 KB 对齐、模块入口和原生库包装检查通过。

发布清单仅包含产品源码、图标、编译期公开依赖及许可、构建与测试脚本、文档。发行源码与实际构建输入按文件 SHA-256 核对，源码归档按同一清单生成。APK、源码归档、构建信息及校验清单作为四个 Release 附件提供。

对上传清单和 APK 条目重新检查私钥、账号令牌、云密钥、口令赋值、带凭据 URL、本机绝对路径、设备序列号、局域网地址和个人邮箱模式。签名密钥、本机账号配置、设备采集记录、截图录像与厂商 ROM 不参与上传；原有品牌素材与依赖许可保留。

发行 APK 在本机签名。GitHub 发布只使用本仓库自动提供的短期令牌，不向仓库或发布作业传入签名私钥、个人令牌或密码。源码、附件和 GitHub 元数据完成身份及摘要检查后才发布正式版本。

本次正式 APK 未额外安装手机。完整构建、离线回放和既有实机证据分别记录，详见[验证范围](验证说明-1.0.1.md)。模式检查不能替代完整安全审计。
