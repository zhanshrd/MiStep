# 1.0.1 分身适配候选

此版本在已发布的 `com.jiusis.mistep` 1.0.0 基线上继续开发，版本码为
`1000001`。1.0.0 标签和发行附件保持本次已核验的内容。

## 调整

- 本体任务、分身任务、桌面以及其他副任务分别记录用户身份，交换双方
  不再共用一个 `userId`。恢复和过渡快照继续逐项核对任务、token、用户、
  显示屏及原有 Shell organizer 的归属。
- 收纳门禁与现有主任务识别保持一致：关联 profile 的任务已获焦时，
  兼容 ROM 把 `isVisible` 报为 false 的情况；隐藏且未获焦的任务仍被拒绝。
- 收纳分身后核对主用户桌面，提升分身后按该任务自己的用户身份交接焦点。
- 通知仍使用原始 PendingIntent 和参数；同包本体与分身按通知用户分别
  匹配副任务，不因包名相同就提升另一个实例。

## 验证与边界

完整 Java/C++ 源码构建、签名、16 KB 对齐与模块包装检查通过。既有
44 个策略程序、38 个生产方法回放入口与 3 个 WMS 程序通过；新增
`tools/clone-users-jvm/run.py` 对真实收纳、其他副任务检查方法和请求
契约补充回放。

覆盖 0→999、999→0、999→999 交换、独立用户的过渡快照、逆向恢复、
999 应用与 0 桌面交接、混合用户副任务及错误用户、任务 ID、token、
显示屏、owner 和 Surface 层变化拒绝。999 是测试样例，产品不会将
该编号硬编码为分身；仅接受系统返回的当前用户及关联 profile。

候选包尚未安装或完成分身真机验收，不宣称所有 ROM 的分身实现都已
适配。需要在已有分身的设备上有界验证收纳、两个方向交换、回到桌面、
通知与退出恢复，并核对实际任务身份和触摸；故障即停并恢复。

这是开发候选，没有发布为新的正式 GitHub Release。正式安装与旧包名
迁移步骤继续见[使用说明](使用说明.md)。
