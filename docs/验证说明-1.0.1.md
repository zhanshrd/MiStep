# 1.0.1 验证范围

正式版本为 `1.0.1`，版本码 `1000034`，包名 `com.jiusis.mistep`。产品逻辑以最终测试候选 `1000033` 为基线，保留其顶部真实应用层归还与 `1000032` 的原生控制中心图标修正。

## 构建与离线检查

正式 APK 使用全新隔离目录，从完整 Java 和 C++ 源码编译，执行项目全部离线策略测试、生产方法回放、签名、16 KB 对齐及模块入口/原生库包装检查。发行构建信息随附件提供。

离线回放覆盖分身用户隔离、全屏入口、顶部任务配置和输入、任务归还、系统面板触区、自定义快捷应用、原生图标资源、歌词译文对齐、剪贴板清空及已有主副任务链路。模拟测试通过不等同于所有应用和机型的真实体验通过。

## 已有实机证据

- Redmi Note 11T Pro：测试期已验证分身与本体同时保留、收纳和双向交换；沉浸页面先显状态栏再另起入口手势；快捷应用长按、搜索、多选、保存、取消固定及取消不保存。
- Redmi Note 11T Pro：最终图标候选已核控制中心图案、付款码/乘车码按钮和正常退出；最终顶部候选已核真实应用画面返回、已有主区保留、后续触摸及退出恢复。
- Xiaomi 17 Pro Max：部分测试候选已安装和加载；不将这些结果视为全部最新功能都完成该机验收。

本次正式 APK 重新完整打包，未额外安装到手机。歌词译文、剪贴板新修正、顶部返回取消/超时及所有第三方应用组合，不宣称已经统一完成实机验收。

## 保留问题

部分机型主区域不缩放、部分图文打开评论时图片错位，以及与其他手势模块的兼容反馈仍在跟进。旧的标准抖音图片专用注入已撤回，本版不声称已修好该图文问题。

普通使用推荐系统框架和系统界面。小米输入法的横屏自动悬浮兼容仍为可选应用内策略，不宣称已完全迁移到系统端。
